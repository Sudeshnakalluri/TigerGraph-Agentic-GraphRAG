💡 Hackathon Research Thesis: When Does An Agent Matter?

The headline goal of this investigation: Determine when a complex question requires an autonomous multi-step agent versus when simpler RAG or GraphRAG is sufficient or faster.

✅ High-Value Agentic Sweet Spots

Aggregation (+57% EM), Multi-Hop (+38% EM), and Temporal (+40% EM): These questions cannot be answered with single-step embeddings. The Agent dynamically invokes AggregationReasonerTool, navigates PREVIOUS_EDITION graph edges, and performs multi-hop pathfinding connecting Venue, Date, Event, and Athlete.

⚡ Where Agents Are Overkill (19% of Queries)

Single-Event Fact Lookups: When retrieving a factual infobox value (e.g. competitors in a specific event), Standard RAG matches accuracy with 65% lower latency and 40% fewer tokens. The QueryComplexityRouter accurately bypasses agentic overhead on these queries.
